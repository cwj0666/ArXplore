---
title: 스트림 종료 판정과 인용 링크 호스트 검증
date: 2026-09-25
area: [frontend, agent]
decision: 클라이언트는 [DONE] 없이 끝난 SSE 스트림을 오류로 다루고, 인용 검증은 링크 호스트가 arxiv.org 계열일 때만 arXiv ID를 인정하며, 실패한 턴과 현재 질문의 중복은 대화 이력에서 뺀다
---

**결정과 근거** — 리뷰 지적으로 스트림과 인용의 경계를 보강했다. (1) `frontend/src/helpers/sse.ts`는 `[DONE]` 없이 연결이
끝난 스트림을 성공으로 처리했다. 잘린 답변이 완성된 답처럼 남으므로 `StreamEventError`("응답이 완료되기 전에 연결이
끊겼습니다.")로 바꿨다(f229c59). (2) 인용 검증의 arXiv ID 추출은 URL 어디서든 `arxiv.org/abs/`를 찾는 정규식이었다. URL을
분해해 scheme이 http(s)이고 host가 `arxiv.org`, `www.arxiv.org`, `export.arxiv.org`일 때만 경로에서 ID를 읽게 했다(4c358d5).
(3) 실패한 턴은 이력에서 빼고(f229c59), 상세 챗 이력 끝에 현재 질문이 한 번 더 들어오면 클라이언트와 서버 양쪽에서
지운다(515e211). (4) PDF 링크처럼 외부 URL을 여는 곳은 http(s)만 허용한다(`safeUrl.ts`).

**트레이드오프** — 호스트 허용 목록은 arXiv 미러나 단축 URL로 건 링크를 인용으로 인정하지 않는다. 잘린 스트림을 오류로
표시하면 사용자는 그때까지 받은 부분 답을 오류와 함께 보게 된다.

**eval 영향** — `test_agent_guardrails.py`의 `test_arxiv_id_from_url_requires_real_arxiv_host`,
`test_lookalike_domain_is_not_attributed_to_an_arxiv_hit`, `test_link_matches_by_arxiv_id_across_abs_pdf_and_version`,
`test_api_views.py`의 `test_current_question_echoed_in_history_is_dropped`,
`test_only_trailing_user_turn_matching_current_message_is_dropped`. 행동 지표 `no_fabricated_links`는 같은 추출 함수를 쓰므로
유사 도메인 링크는 hit과 연결되지 않고 날조 링크로 셈에 들어간다.

**알려진 한계** — `sse.ts`의 잘린 스트림 처리는 프론트엔드 테스트 러너가 없어 자동 테스트가 없다.

**트러블슈팅** — arXiv 유사 도메인 링크가 인용으로 인정됨

- 증상: 답변 속 링크가 `arxiv.org`가 아닌 호스트를 가리켜도 경로에 `arxiv.org/abs/<id>` 모양이 있으면 해당 arXiv hit의 인용으로
  `in_answer` 표시를 받을 수 있었다.
- 원인: `_ARXIV_URL_PATTERN`이 URL 문자열 어디에서든 `arxiv\.org/(abs|pdf)/`를 검색했고 호스트를 확인하지 않았다.
- 확인 방법: 3차 리뷰에서 지적됐고, 다른 호스트에 같은 경로를 붙인 링크로 재현하는 테스트를 만들었다
  (`test_lookalike_domain_is_not_attributed_to_an_arxiv_hit`).
- 해결: `urlsplit`으로 scheme과 hostname을 확인한 뒤 경로에서만 ID를 읽는다(4c358d5).
  `test_arxiv_id_from_url_requires_real_arxiv_host`의 매개변수 사례들이 통과한다.
- 재발 방지: 평가의 `no_fabricated_links`가 제품과 같은 추출 함수를 쓰는지 `test_link_extraction_uses_product_rules`가 확인한다.
