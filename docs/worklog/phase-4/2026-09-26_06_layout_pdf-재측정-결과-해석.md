**결정과 근거** — 검색 `eval/results/20260926-103105.md`와 생성 `eval/results/generation_20260926-103836.md`(답변
`answers_20260926-103836.jsonl`)를 첫 실측 `20260925-225658.md`·`generation_20260925-233840.md`와 비교했다. 코퍼스는
같은 날 "HURIDOCS 코퍼스 재구축" 항목의 `layout_pdf` 275편이고, 수식·표 파싱은 꺼져 있다. 결과는 커밋 72051ff에 있다.

질의셋은 `eval/queries.jsonl`(sha256 82e4a51cce90) 142개다. known-item 57개는 첫 실측 파일의 줄을 그대로 썼다(같은 seed로
뽑으면 같은 30편이지만 LLM 문장이 달라지므로 재생성하지 않음). 청크 합성은 `--mode chunk_synth --chunks 15 --seed 42`로
다시 만들었고 어휘 겹침 필터가 4개를 버려 11개가 남았다. 케이스 카탈로그 74개는 `--attach-ids`로 채웠다. `0000.0000m`
(appendix 청크 조건)은 레이아웃 파싱으로 appendix 청크가 달라져 자동 선택이 바뀌었으므로, 비교를 위해 첫 실측 값
2609.24115로 `--set` 고정했다(오늘도 조건을 만족하는 후보다). 검색 평가 대상은 111개(ko 58 / en 53)다.

논문 단위 전체(첫 실측 → 이번): lexical hit@1 0.539→0.514, hit@10 0.643→0.649, MRR@10 0.573→0.552; vector hit@1
0.704→0.739, hit@5 0.809→0.865, hit@10 0.826→0.883, MRR@10 0.741→0.785; hybrid hit@1 0.704→0.730, hit@5 0.809→0.865,
hit@10 0.817→0.883, MRR@10 0.737→0.787. known-item 57개의 hit@10은 lexical 0.667, vector·hybrid 1.000으로 같고 hit@1은
vector 0.930→0.895, hybrid 0.930→0.912로 내려갔다. manual 43개 hit@10은 0.581/0.581/0.558 → 0.674/0.721/0.721이다.
query_form 12개는 0.333/0.250/0.167 → 0.667/0.917/0.917인데 주제 질의 라벨을 집합으로 고친 효과가 섞여 있다(recall@10
0.326/0.512/0.522). 다논문 관점(6개) hybrid hit@10은 0.667 → 0.500으로 내려갔다. noise@10은 세 방식 모두 0.000이다.

청크 단위(청크 합성 11개)에서 hybrid chunk hit@5는 0.636, vector 0.636, lexical 0.273이다(첫 실측은 다른 15개에서 0.533 /
0.533 / 0.467). `lexical_nofilter`도 0.273, `hybrid_nodiv`도 0.636이라, 첫 실측에서 필터가 정답 청크를 걸러 내던 현상
(2026-09-26 참고문헌 휴리스틱 항목)은 이번 질의에서 보이지 않는다. `hybrid_plainrrf`는 청크 hit@5 0.727로 가장 높지만
논문 단위 hit@1이 0.577로 가장 낮다.

생성(첫 실측 → 이번): agent faithfulness 0.870→0.865, answer_relevancy 0.654→0.667, context_precision 0.737→0.870;
paper_chat 0.928→0.913, 0.577→0.563, 0.807→0.892. context_precision은 청크 합성 질의에서만 계산되어 표본이 10~11건이다.
행동 지표: 에이전트 거절 정확도 0.933 → 1.000(15건), 상세 챗 0.833(6건) 그대로, 날조 링크 없음은 두 모드 모두 1.000,
상세 챗 금지 문자열 없음은 1.000 → 0.800(5건)으로 회귀했다(같은 날 "상세 챗 사용자 메시지 인젝션" 항목). answer 케이스
거절은 에이전트 7건 → 7건, 상세 챗 12건 → 9건이다. 에이전트가 영어 질의에 한국어로 답한 건수(한글 글자 비율 30% 초과)는
22/63 → 4/61이다.

기본 검색 방식은 hybrid로 둔다. hit@5·hit@10은 vector와 같고 MRR은 0.787 대 0.785로 비슷하지만, hit@1은 0.730 대 0.739로
조금 낮고 지연은 2.8배다. 첫 실측에서 근거로 든 "영어 lexical hit@1이 vector보다 높다"는 이번에 성립하지 않았다(0.717 대
0.774). 남은 이유는 임베딩 키가 없을 때의 lexical 폴백을 한 경로로 관리하는 것뿐이라, vector 단독 전환은 로드맵에 남긴다.

**트레이드오프** — 파서·검색 휴리스틱·질의셋·에이전트 프롬프트가 한꺼번에 바뀐 비교다. 첫 실측은 커밋 5f9c4cd, 이번은
de56bf6에서 쟀다. 그사이 `src/` 변경은 `src/integrations/paper_retriever.py`(참고문헌 오판 휴리스틱: lexical 필터와 vector
감점)와 `src/core/prompts/agent.py`(검색 전 거절 금지, 질문 언어로 답하기) 두 파일뿐이다. 따라서 `content_role` 분포 변화는
순수한 파서 효과이고, 검색 지표에는 휴리스틱 변경이, 생성 행동 지표에는 프롬프트 변경이 섞여 있다. 파서만 바꾼 통제 실험(같은
코드·같은 질의로 pypdf와 layout_pdf 비교)은 pypdf 코퍼스를 다시 만들어야 해서 하지 않았다. 지연은 측정 장비가 달라(파드 CPU 쿼터
약 15코어, 로컬 DB) 비교하지 않는다.

**eval 영향** — README Evaluation 절의 표를 이 측정으로 교체하고 첫 실측은 한 줄 비교로 남겼다. 커밋된 질의셋
(`eval/queries.jsonl`, `queries.generated.jsonl`, `queries.cases.jsonl`)이 다음 재측정의 기준이다. 영어 질의의 한국어 답변
건수는 여전히 행동 지표가 아니라 답변 파일에서 셌다.

**알려진 한계** — 단일 실행이라 분산을 모른다. 청크 합성 질의 11건은 1건이 청크 hit@5를 0.091 움직이고 첫 실측의 15건과
질의가 달라 비율만 참고한다. 청크 합성 질의 중 `cs-1892`("각 이메일 주소는 몇 개의 계정 등록에…"), `cs-15460`("maximum
allowed regret…")은 논문을 특정하지 않아 모호하지만 사람 검토 없이 그대로 두었다. `cs-1892`는 에이전트가 거절한 7건에 들어
있다. 카탈로그 자동 선택 중 `0000.0000d`(MoE 라우팅 → 장면 텍스트 인식 MoE 논문), `e`(긴 문맥 → in-context 로봇 학습),
`q`(양자화 → 벡터 양자화 토크나이저)는 조건에 잘 맞지 않지만 첫 실측과 같은 선택이라 유지했다. 수식·표 파싱을 켠 운영 조건의
수치는 없다.
