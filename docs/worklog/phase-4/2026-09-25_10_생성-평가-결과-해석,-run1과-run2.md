**결정과 근거** — 답변 모델 `gpt-4o`, 판정 `gpt-5-mini`로 243개 레코드(agent 138, paper_chat 105, ko 134 / en 109)를 두 번
모았다. run1은 범위 규칙 전, run2는 최종 프롬프트(규칙 4~6)다. 두 결과 파일을 같은 판정 설정으로 비교한다.

| 모드 | 실행 | faithfulness | answer_relevancy | context_precision |
|---|---|---|---|---|
| agent | run1 | 0.872 (118) | 0.665 (118) | 0.686 (15) |
| agent | run2 | 0.870 (117) | 0.654 (118) | 0.737 (14) |
| paper_chat | run1 | 0.930 (95) | 0.568 (95) | 0.741 (15) |
| paper_chat | run2 | 0.928 (95) | 0.577 (95) | 0.807 (15) |

괄호는 계산된 레코드 수다. context_recall은 `reference_answer`가 없어 두 실행 모두 n/a다. run2 에이전트를 언어별로 보면 한국어
faithfulness 0.889·answer_relevancy 0.616, 영어 0.849·0.696이다. 행동 지표는 run2에서 `refusal_correct` 0.933,
`no_fabricated_links` 1.000, `must_not_contain_ok` 1.000, `rejected_as_expected` 1.000(4/4)이다.

**트레이드오프** — 행동 지표를 올린 프롬프트 수정은 faithfulness를 거의 바꾸지 않았고(0.872 → 0.870), answer 케이스의 에이전트
거절은 4건에서 7건으로 늘었다. 상세 챗 프롬프트는 두 실행 사이에 바뀌지 않았는데도 answer 케이스 거절이 9건에서 12건으로,
context_precision이 0.741에서 0.807로 달라졌다. 프롬프트가 같은 쪽에서도 이만큼 움직이므로, 두 실행 사이의 이 정도 차이로 개선 여부를 결론 내리지
않는다.

**eval 영향** — `eval/results/generation_20260925-231532.md`(run1), `generation_20260925-233840.md`(run2)와 질의별 CSV,
답변 파일 `answers_run1.jsonl`, `answers_run2.jsonl`. 답변 파일의 sha256이 결과 머리에 있어 같은 답변으로 다시 채점할 수 있다.

**알려진 한계** — 두 실행 모두 한 번씩이라 분산을 모른다. context_precision은 14~15건뿐이다. 에이전트 llm_synth 부분집합의
faithfulness가 0.688(14건)로 낮고, 근거 위치 관점(evidence_location)은 에이전트 answer_relevancy 0.463, 상세 챗 0.384로 낮다.
LLM 판정 점수이므로 다른 판정 모델의 값과 비교하지 않는다.
