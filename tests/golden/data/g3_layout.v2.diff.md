# G3 layout 골든 v2 변형: 원본과 다른 점

변형 파일은 `g3_layout/<arxiv_id>.v2.json.gz` 10개이고 `GOLDEN_IMPL=v2`일 때만 쓰인다. 원본 `g3_layout/<arxiv_id>.json.gz`는 옛 구현 기준으로 그대로 둔다.

- `request`, `response`, `response_sha256` 등 HURIDOCS 쪽 필드는 원본과 같다.
- 바뀌는 것은 기록된 응답을 다시 파싱한 `parse`, `chunks`, `chunk_metrics`뿐이다.
- 변형은 원본 골든의 `response`를 v2 파서 어댑터로 재생해 만들었다. HURIDOCS를 다시 호출하지 않았다.
- 원본 골든(c7f7575)은 F31 커밋(c6bd198) 뒤, F01 커밋(6aaebfa) 전에 들어왔다. 그래서 F01~F03 커밋 때는 이 변형이 없었고, F04 뒤 이 커밋에서 한꺼번에 기록한다.
- 수정 ID별 기여는 각 커밋의 파서(e4b84ee, 6aaebfa, c34348c, 1def840, e07339c)로 같은 응답을 재생해 나눴다.
- 이식 동등성: e4b84ee의 v2 파서로 재생한 결과는 원본 골든과 10/10 같다.

- F01 결과에서 규칙이 작동한 청크는 다음과 같다.
  - 짧은 첫 문장 삭제 31개(735자)
  - bullet 앞부분 삭제 13개(공백 제외 552자)
