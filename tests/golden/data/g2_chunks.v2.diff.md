# G2 청크 골든 v2 변형: 원본과 다른 점

변형 파일은 `g2_chunks.v2.json.gz`이고 `GOLDEN_IMPL=v2`일 때만 쓰인다. 원본 `g2_chunks.json.gz`는 옛 구현과 DB `paper_chunks` 기준으로 그대로 둔다.

다시 만드는 명령(저장소 루트): `GOLDEN_IMPL=v2 v2/.venv/bin/python -m scripts.goldens.capture_g2_chunks --variant v2`

- 입력은 원본과 같다. 골든 DB의 `paper_fulltexts.sections` 275편이다.
- 이식 동등성: 95adc76 시점에 v2는 원본 골든과 275/275편, 16,010/16,010청크가 같았다.
- 변형과 비교하면 원본의 두 검사는 실패한다. `test_golden_covers_the_corpus`는 청크 수 16,010을, `test_golden_matches_the_database_chunks`는 DB `paper_chunks`와 같은지를 본다. 둘 다 원본 골든을 확인하는 검사다. 논문별 비교(`test_chunks_match_golden`)는 275/275가 통과한다.

## F01: 청크 겹침이 실제로 적용되게

다음 청크의 시작을 `끝 - 200` 근처에서 찾는다.
- 찾는 범위는 `[끝 - 300, 끝 - 100]`이다.
- 문장 시작(`. ? !` 뒤 공백 다음의 소문자 아닌 글자, 또는 빈 줄 다음)이 있으면 목표에 가장 가까운 곳을 고른다.
- 없으면 단어 시작, 그것도 없으면 목표 위치 그대로다.
- 시작은 항상 이전 시작보다 뒤, 이전 끝보다 앞이다.
- 옛 조각 건너뛰기 규칙(소문자 단어·인용 조각으로 시작하면 다음 문장으로 넘김)은 없앴다.
- 흡수 판정은 이전 청크 뒤의 새 내용만 본다. 흡수할 때도 새 내용만 이어 붙여 겹친 부분이 한 청크 안에서 반복되지 않는다.

## F02: 청크 앞부분을 지우던 규칙 제거

청크 텍스트는 이제 섹션 원문 구간 `[char_start, char_end)`를 strip한 것 그대로다. 없앤 규칙은 다음과 같다.
- 짧은 첫 문장 삭제: 6단어 이하의 첫 문장 뒤에 대문자 문장이 오면 첫 문장을 지우고 청크 전체의 공백을 한 칸으로 압축했다. 번호 제목 뒤에 본문 시작어가 오면 제목 부분을 지우는 분기도 같은 함수였다.
- bullet 앞부분 삭제: 앞 220자 안에 `• `가 있고 그 앞이 평범한 글자뿐이면 bullet까지 지웠다.
- 앞머리 `,;:)]}` 삭제
- 흡수 구분자: 같은 섹션 안에서 흡수할 때 사이 공백을 `\n`으로 바꾸던 것을 원문 구간 그대로 둔다. 제목만 같고 섹션이 다른 흡수는 예전처럼 `\n`으로 잇는다.

- 공백만 바뀐 청크는 264개다(흡수 구분자).

## F03: 청크 최대 길이를 실제 상한으로

청크 끝을 `[시작 + 900, 시작 + 1800]` 안에서만 찾는다. 예전에는 `시작 + 1800 + 220`까지 봤다. 우선순위(문단·문장 경계 → 줄바꿈 → 공백)는 그대로이고, 경계가 없으면 `시작 + 1800`에서 자른다. 흡수는 합친 결과가 1,800자 이하일 때만 한다.
